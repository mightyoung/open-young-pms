## 38. 质量管理模块

### 38.1 质量标准库
- **功能：** 维护项目质量检查标准，支持分类管理
- **字段：**
  - 标准名称（name）
  - 分类（category）：钢筋混凝土 / 电气安装 / 给排水 / 装饰装修 / 其他
  - 检查要点（checkpoints）
  - 合格标准（standard）
  - 关联项目（project_id）
  - 创建人 / 创建时间
- **API：** `GET/POST /quality/standards`
- **页面：** 系统智能 → 质量管理

### 38.2 质量检查记录
- **功能：** 记录每次质量检查的结果（合格 / 不合格）
- **字段：**
  - 关联标准 ID（standard_id）
  - 项目 ID（project_id）
  - 检查人（inspector_id）
  - 检查时间（inspected_at）
  - 结果（result）：pass / fail
  - 备注（remarks）
  - 附件（attachments）
- **API：** `GET/POST /quality/inspections`
- **页面：** 系统智能 → 质量管理 → 检查记录

## 42. 数据服务模块

### 42.1 数据字典
- **功能：** 统一管理系统数据标准（隐患类型、紧急程度等）
- **字段：**
  - 编码（code）
  - 名称（name）
  - 分类（category）
  - 数据类型（data_type）
  - 选项列表（options）
  - 说明（description）
- **API：** `GET /data/dict`
- **页面：** 系统管理 → 数据字典

### 42.2 质量评分规则
- **公式：** 综合分 = 完整性×30% + 准确性×30% + 一致性×20% + 时效性×20%
- **评分维度：**
  - 完整性（completeness）：必填字段填写率
  - 准确性（accuracy）：数据格式规范率
  - 一致性（consistency）：跨表数据一致率
  - 时效性（timeliness）：数据更新及时率
- **API：** `POST /data/quality-rules`

### 42.3 数据血缘分析
- **功能：** 分析表级和字段级数据血缘
- **分析维度：**
  - 表级血缘（上游表 → 当前表 → 下游表）
  - 字段级血缘（上游字段 → 当前字段 → 下游字段）
- **API：** `POST /data/lineage`
- **页面：** 数据治理 → 数据血缘

### 42.4 元数据管理
- **功能：** 数据资产分级管理
- **分级标准：**
  - S 级（核心资产）：敏感度高，需严格保护
  - A 级（重要资产）：重要业务数据
  - B 级（一般资产）：内部使用数据
  - C 级（低价值资产）：公开或归档数据
- **字段：** 名称、数据分级、所有者、描述、更新周期
- **API：** `POST /data/metadata`
- **页面：** 数据治理 → 元数据管理

### 42.5 数据质量验证
- **功能：** 基于规则的数据质量验证
- **规则：** 非空校验 / 格式校验 / 唯一性校验 / 范围校验
- **API：** `GET /data/validate`

## 43. 随手拍增强

### 43.1 GPS 定位
- 移动端支持 GPS 获取当前位置
- 上报时自动附带经纬度（latitude, longitude）
- 支持手动校正位置

### 43.2 现场照片
- 支持拍照上传最多 3 张现场照片
- 照片自动压缩（最大 2MB）
- 照片自动关联隐患记录
- 支持照片预览和删除

### 43.3 自动派发规则
- **功能：** 基于类型 / 紧急程度的自动派发规则
- **规则引擎：**
  - 类型 = safety + 紧急 = urgent → 自动派给安全主管
  - 类型 = quality + 紧急 = normal → 自动派给质量主管
  - 类型 = environment → 自动派给环保专员
- **配置：** 支持自定义派发规则（类型 + 紧急程度 → 接收人）
- **页面：** 系统管理 → 派发规则配置

## 47. 通知设置

### 47.1 通知渠道
- **应用内（in_app）：** 始终开启
- **邮件（email）：** 可选开启
- **短信（sms）：** 可选开启（预留）

### 47.2 通知频率
- **实时（realtime）：** 立即推送
- **每日摘要（daily）：** 每天汇总推送
- **每周摘要（weekly）：** 每周一推送

### 47.3 通知类型
- **审批（approval）：** 审批请求、审批结果
- **提及（mention）：** 被 @ 时的通知
- **隐患（hazard）：** 隐患上报、隐患处理进展
- **报告（report）：** 报告提交结果、报告审批结果
- **系统（system）：** 系统公告、系统通知

### 47.4 API
- `GET /notification-settings` — 获取通知设置
- `PUT /notification-settings` — 更新通知设置
